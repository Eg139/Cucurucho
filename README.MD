## 🚀 ¿Qué es Cucurucho?
**Cucurucho** es un sistema de ventas ultraliviano, rápido y de código abierto diseñado para atención en mostrador. Funciona completamente offline como Progressive Web App (PWA).

### Características principales:
- **Catálogo dinámico:** Configurable para tus productos y precios.
- **Carrito de ventas ágil:** Pensado para máxima velocidad en la atención.
- **Cierre de caja:** Reportes diarios y mensuales con exportación a CSV.
- **Soberanía de datos:** Todo se almacena localmente en el dispositivo (`localStorage`). Sin servidores en la nube ni costos ocultos[cite: 1, 3].
